## 🏆 Competitive Programming Training

This repository documents my journey preparing for programming competitions. My training focuses on:

- Quickly and accurately interpreting problem statements.
- Identifying patterns in arrays, strings, maps, and simulations.

## ✏️ My problem-solving routine

Every problem is an opportunity to improve:

1. **Understand** — What is the problem actually asking?
2. **Analyze** — What information do I have? What are the constraints?
3. **Plan** — Can I describe the solution before coding?
4. **Implement** — Write the simplest correct solution.
5. **Test** — Check edge cases and possible mistakes.
6. **Reflect** — What did I learn? Could I solve it independently next time?

## 🌱 My learning principles
